# YouTube Harvester 1.1.2

This release expands Quick Download with multi-track media selection and adds
complete Japanese localization.

> **UPD 2:** Multiple audio tracks and subtitles can now be embedded into one
> video. Archive variants preserve their quality and track selection, subtitle
> failures are handled gracefully, and Japanese is fully supported.

## Highlights

- Select multiple audio tracks and manual or automatic subtitles in Quick
  Download and embed them into one MP4.
- Keep separate archive variants for different resolutions, audio tracks, and
  subtitle selections.
- Inspect selected tracks in the archive quality tooltip.
- Discover alternate dubbed tracks through the additional YouTube metadata
  client.
- Continue downloading when individual subtitle tracks fail or return HTTP
  429.
- Use the complete Japanese interface, README, changelog, rules, and localized
  screenshots.
- Drag the Quick Download window smoothly on Windows without position-save
  jitter.

## Release Files

- `YouTubeHarvester_1.1.2_linux_all.deb`
- `YouTubeHarvester_1.1.2_source.tar.gz`
- `YouTubeHarvester_1.1.2_windows_setup.exe`
- `YouTubeHarvester_1.1.2_windows_x64.msi`
- `YouTubeHarvester_1.1.2_windows_portable.zip`
- `SHA256SUMS-linux.txt`
- `SHA256SUMS-windows.txt`

Windows packages bundle `yt-dlp`, FFmpeg/FFprobe, and Deno. Python is not
required on the target Windows computer. The Linux package uses the Python
downloader and the standard per-user configuration directories.

Use the checksum files to verify downloaded artifacts.

## Русский

Версия `1.1.2` добавляет выбор нескольких аудиодорожек и субтитров с их
