# YouTube Harvester 1.2.1

## Desktop

- Windows and Linux use the same current desktop sources, including Rutube
  channels and show collections, source-aware archives, scheduling, and limits.
- Download interruption recovery and subsequent download starts retain the
  fixes from the Linux branch.
- Updated pinned dependencies, FFmpeg/FFprobe, and Deno are used in both builds.
- Application, Debian, Inno Setup, and MSI versions are aligned at `1.2.1`.
  Publication defaults no longer mark this version as beta or prerelease.

## Android

- All four ABI variants use version `1.2.1`, version code `120100`.
- Existing component, download recovery, encrypted transfer, and archive
  relinking fixes are retained.
- The internal `legacyBeta` build type is only for signature-compatible private
  tester updates. Its name does not appear in the application version.
- Changing the version does not close the permanent-signing, native source,
  migration, or additional-device acceptance gates. Public Android publication
  remains blocked until those checks are complete.

These notes describe the local release preparation, not an announcement that
artifacts have been published.
