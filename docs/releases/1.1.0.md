# YouTube Harvester 1.1.0

This release adds a fully multilingual interface and documentation, expands
channel and download diagnostics, improves queue processing, and hardens the
Linux and Windows builds.

## Highlights

- Eight complete interface languages: English, Russian, Ukrainian, French,
  Spanish, Hindi, Chinese, and Arabic. New installations start in English.
- Separate README, changelog, and four current UI screenshots for every
  supported language.
- Original cached channel artwork in the new screenshots and channel view.
- Paid-content status per channel with optional members-only checks.
- Queue processing before channel scanning and a second pass after all channels.
- Daily download totals split into Videos, Shorts, live streams, and queue items.
- All, Important, and Errors log filters.
- Built-in `yt-dlp` version check and expanded environment diagnostics.
- Refined Overview, settings, channel controls, checkboxes, and Quick Download.
- Better UTF-8 handling on Windows and safer temporary-file cleanup on Linux.

## Platform Notes

### Windows

The Setup EXE, MSI, and portable ZIP bundle `yt-dlp`, `ffmpeg.exe`,
`ffprobe.exe`, and `deno.exe`. Python is not required on the target computer.
The global Quick Download hotkey uses the native Windows API.

### Linux

The `.deb` uses the Python downloader and standard per-user data directories.
X11 global hotkeys use `pynput`. On Wayland, the application can install a
Cinnamon/GNOME system shortcut and can monitor the clipboard through
`wl-clipboard`.
