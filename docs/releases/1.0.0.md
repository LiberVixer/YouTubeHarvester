# YouTube Harvester 1.0.0

## Главное

Это первый стабильный релиз YouTube Harvester. Программа прошла большой цикл
доработок интерфейса, Windows-сборки, быстрого скачивания, архива, Telegram и
Linux/Windows runtime-логики.

## Что внутри

- Единый Python-движок скачивания для Linux и Windows.
- Быстрое скачивание из буфера обмена с выбором разрешения, немедленным
  скачиванием, добавлением в очередь и Telegram-чекбоксом.
- Глобальная горячая клавиша `Ctrl+Shift+Alt+Y` по умолчанию.
- Поддержка Linux/X11 hotkey через `pynput` и системной команды
  `yt-harvester --quick-download` для Wayland-сценариев.
- Отслеживание буфера обмена для YouTube-ссылок.
- Вкладка обзора с живым статусом, счётчиками, прогрессом проверки каналов,
  текущим типом контента и последними событиями.
- Каналы с отдельными переключателями для Видео, Shorts и Трансляций.
- Очередь, планировщик и архив скачиваний.
- Telegram-настройки в интерфейсе и сохранение в `.env`.
- Защита Windows-логов и архива от проблем кодировки.
- Более безопасная очистка временной папки.
- Windows-сборка с bundled `ffmpeg.exe`, `ffprobe.exe` и `deno.exe`.
- Новые README, скриншоты, заставка ожидания скачивания и release packaging.
