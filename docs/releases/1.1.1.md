# YouTube Harvester 1.1.1

This maintenance release fixes several small interface and download-flow
issues on Linux and Windows.

> **UPD 1.1.1:** Minor issues have been fixed.

## Fixes

- Every completed channel video is moved from the temporary directory to the
  selected download directory before the next playlist item starts.
- A soft stop safely preserves and moves the video that has already finished.
- The active channel artwork is displayed during downloads even when the
  hidden Harvester game victory logo has been unlocked.
- Minor interface and runtime inconsistencies were corrected.

## Release Files

- `YouTubeHarvester_1.1.1_linux_all.deb`
- `YouTubeHarvester_1.1.1_source.tar.gz`
- `YouTubeHarvester_1.1.1_windows_setup.exe`
- `YouTubeHarvester_1.1.1_windows_x64.msi`
- `YouTubeHarvester_1.1.1_windows_portable.zip`
- `SHA256SUMS-linux.txt`
- `SHA256SUMS-windows.txt`

Windows packages bundle `yt-dlp`, FFmpeg/FFprobe, and Deno. Python is not
required on the target Windows computer. The Linux package uses the Python
downloader and the standard per-user configuration directories.

Use the checksum files to verify downloaded artifacts.
