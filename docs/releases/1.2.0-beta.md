# YouTube Harvester 1.2.0 Beta

This beta expands manual downloads beyond YouTube while preserving the
existing YouTube channel-monitoring workflow. Individual Rutube and VK videos
can now pass through the same Overview field, Quick Download window, clipboard
watcher, queue, and archive.

> **Prerelease:** this build is published for testing. Keep a backup of the
> application data directory before testing archive migration with important
> records.

## Highlights

- Download individual videos from YouTube, Rutube, and VK through one workflow.
- Keep archive identities separate by source and media ID, with working source
  links and compact service symbols.
- Preserve compatibility with existing YouTube archive records and variants.
- Use refreshed and pinned downloader, JavaScript runtime, media tools, Python
  dependencies, and GitHub Actions.
- Verify exact Windows component versions and SHA-256 checksums in both online
  and offline builds.
- Download preview images with protocol, redirect, timeout, and size checks.
- Use the new close button beside the theme selector and more compact archive
  channel and ID columns.

## Release Files

- `YouTubeHarvester_1.2.0-beta_linux_all.deb`
- `YouTubeHarvester_1.2.0-beta_source.tar.gz`
- `YouTubeHarvester_1.2.0-beta_windows_setup.exe`
- `YouTubeHarvester_1.2.0-beta_windows_x64.msi`
- `YouTubeHarvester_1.2.0-beta_windows_portable.zip`
- `SHA256SUMS-linux.txt`
- `SHA256SUMS-windows.txt`

Windows packages bundle `yt-dlp`, FFmpeg/FFprobe, and Deno; Python is not
required on the target computer. The Debian package version is
`1.2.0~beta1`, which allows a future stable `1.2.0` package to replace it
correctly.

Use the checksum files to verify downloaded artifacts. The built-in updater
performs this verification automatically.

## Русский

Версия `1.2.0-beta` добавляет необязательное скачивание отдельных видео с
YouTube, Rutube и VK через единый интерфейс: Обзор, Быстрое скачивание,
слежение за буфером, очередь и архив. Архив различает источник и ID, поэтому
совпадающие идентификаторы разных сервисов не пересекаются. Компоненты и
сборочная цепочка Windows/Linux обновлены и закреплены точными версиями.

Это предварительный выпуск для тестирования. Перед проверкой миграции важных
записей рекомендуется сохранить резервную копию каталога данных программы.
