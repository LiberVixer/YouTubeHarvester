# YouTube Harvester 1.1.3

This release adds verified in-app application updates, complete Belarusian
localization, a current YouTube downloader, and stronger recovery from
temporary YouTube delivery failures.

> **UPD 3:** YouTube Harvester can now download the correct update package from
> the official GitHub Release, resume an interrupted transfer, and verify the
> file before opening it.

## Highlights

- Check for a new YouTube Harvester version directly from Settings.
- Download the matching Setup EXE, portable ZIP, Linux DEB, or source archive.
- Verify every application update with the published SHA-256 checksum and the
  GitHub asset digest before installation.
- Use the complete Belarusian interface, rules, README, changelog, desktop
  metadata, and localized screenshots.
- Run the bundled `yt-dlp 2026.08.19`; update a managed `yt-dlp` executable
  safely and atomically from Settings.
- Refresh expired YouTube media URLs and retry temporary HTTP 403 failures
  through a fallback player client.
- Use consistent tray/taskbar behavior, safer per-user runtime files, and
  desktop completion notifications for integrations such as FriendsHub.

## Release Files

- `YouTubeHarvester_1.1.3_linux_all.deb`
- `YouTubeHarvester_1.1.3_source.tar.gz`
- `YouTubeHarvester_1.1.3_windows_setup.exe`
- `YouTubeHarvester_1.1.3_windows_x64.msi`
- `YouTubeHarvester_1.1.3_windows_portable.zip`
- `SHA256SUMS-linux.txt`
- `SHA256SUMS-windows.txt`

Windows packages bundle `yt-dlp`, FFmpeg/FFprobe, and Deno. Python is not
required on the target Windows computer. The Linux package uses the Python
downloader and standard per-user configuration directories.

Use the checksum files to verify downloaded artifacts. The built-in updater
performs this verification automatically.
