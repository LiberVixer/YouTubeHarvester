## Shared layout rules

- Portrait mobile layout with a fixed top app bar and fixed five-item bottom navigation.
- Bottom navigation order: Overview, Channels, Queue, Archive, Settings.
- Only the page content scrolls; the app bar and bottom navigation remain visible.
- Dark operational interface with restrained blue accents and compact corner radii.
- Settings use the larger typography and touch targets shown in the three settings mockups.
- These images define visual direction, not exact Android pixel dimensions or final translated copy.
