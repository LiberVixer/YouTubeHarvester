# Версия 1.2.1: Linux, Windows и Android

## Изменения

- Windows собран из текущих общих исходников Linux, включая изменения каналов
  Rutube и подборок шоу, архива, лимитов и восстановления скачиваний.
  SHA-256 одиннадцати общих Python-файлов совпал на обеих машинах.
- Номер приложения Linux/Windows, Debian-пакета, Windows EXE, Setup и MSI:
  `1.2.1`. В EXE проверены FileVersion, ProductVersion и отсутствие IsPreRelease;
  в MSI проверен ProductVersion. Флаги публикации по умолчанию: stable.
- Все четыре Android ABI: versionName `1.2.1`, versionCode `120100`.
  Надпись «БЕТА» заменена номером приложения; отдельный внутренний debug-пакет
  сохраняет суффикс `-debug`. В дистрибутивных тестовых APK этого суффикса нет.
- Версии сторонних библиотек не подменялись номером приложения.

## Проверки

- Linux: 82 теста прошли; версия проверена в метаданных Debian и его исходниках.
- Windows: 80 тестов прошли, два POSIX-теста пропущены штатно. Проверены
  замороженный yt-dlp, запуск встроенного скрипта, FFmpeg/FFprobe, Deno и
  скачивание локального H.264/AAC-видео с ремультиплексированием в MKV.
- Windows: собраны portable ZIP, Setup EXE и MSI. MSI собран существующим WiX
  без автоматического принятия новых лицензионных условий. Установщики
  собраны, но их установка/удаление в этом проходе не проверялись.
- Android: 149 JVM, 31 Python и 36 LDPlayer-тестов прошли без пропусков.
  Debug lint: 0 ошибок, 12 предупреждений о неиспользуемых ресурсах.
- Все четыре Android APK проверены по манифесту, сертификату и ZIP;
  64-битные вложенные ELF прошли проверку выравнивания. ARM APK собраны и
  проверены статически; на ARM-устройстве в этом проходе не запускались.
- Выполнена строгая офлайн-сборка Gradle, проверены контрольные суммы копий.

## Границы

Установленные Linux/Windows приложения не заменялись, работающие скачивания
не прерывались. Основная Android-установка dev33 не менялась; обновлён только
отдельный debug-пакет на LDPlayer. Четыре тестовых APK сохраняют прежнюю
подпись для совместимого обновления существующих тестеров.

Теги, коммиты и публикация не выполнялись. Номер без beta не означает закрытия
публичных Android-гейтов: постоянная подпись финального кандидата, полный
набор исходников native runtime, приёмка миграции и другие устройства ещё нужны.
