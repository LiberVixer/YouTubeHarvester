# QuickJS Android Replacement

Version: 2026-06-04, official source archive from
https://bellard.org/quickjs/quickjs-2026-06-04.tar.xz.
SHA-256: `b376e839b322978313d929fd20663b11ba58b75df5a46c126dd19ea2fa70ad2a`.
This pin was reviewed after downloading upstream over HTTPS; it is not an
independent upstream signature.

```sh
python3 scripts/rebuild_quickjs.py --ndk /path/to/android-ndk-r28c
```

The script builds all four supported ABIs with API 26, NDK 28.2.13676358,
PIE and 16 KB LOAD alignment. Android pthread functions live in libc, so the
target links `-lm -ldl`, not a separate libpthread. The host qjsc compiles the
matching source's REPL bytecode. No compiler-generated bytecode from an older
QuickJS version is reused.

The bundle `quickjs-2026-06-04-16k.zip` includes the MIT license. Its SHA-256 is
`1d12127c7fdbaafa64fe01ad1b1380179c777d9e6c4abe8b8b912e88074a10df`.
The Gradle prepareLibrary task validates this digest and replaces only four
`jni/<ABI>/libqjs.so` entries. Java classes and Python payload are not altered.
APK checks verify native alignment again. This does not update the Python,
OpenSSL or FFmpeg payloads and does not close the complete runtime source gate.
