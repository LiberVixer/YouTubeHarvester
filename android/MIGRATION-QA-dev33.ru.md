Дата: 2026-10-03. LDPlayer Android 14 / API 34 / x86_64.
Это частный QA-прогон, не публикация и не окончательная приёмка релиза.

## Настоящий Экспорт Beta

Экспорт установленной оптимизированной beta выбран через OpenDocument и
импортирован через Настройки в пустую QA-базу. Сообщение об успехе наблюдалось.
Этот первый подписанный APK использует обычную release-оптимизацию приложения
без дополнительных QA API keep rules.

База назначения прошла `integrity_check`. Единственная запись архива, одно
COMPLETED-задание и relink-отпечаток совпали с экспортом после предусмотренной
безопасной нормализации. Старые URI удалены, `file_exists=0`, журнал очищен.
Каналы/очередь/отметки/расписания в реальной исходной базе пусты; заполненный
перенос этих таблиц проверен отдельно искусственным набором.

Затем QA обновлён поверх себя исправленным тестовым вариантом. Через системный
выбор заново предоставлен SAF-доступ к Download/YTH; Refresh в Архиве восстановил
доступность. Новый document URI, имя, размер и SHA-256 файла совпали с экспортом;
остальные записи не изменены. Размер проверенного файла: 535441 байт. Медиа
не перемещались и не удалялись. Исходная beta после всех проверок имеет те же
записи и байты настроек, что до переноса.

## Разные UID И Android Keystore

Opt-in `DataTransferTest#crossIdentityTransferUsesDestinationKeystore` сначала
экспортирует искусственный набор в `.debug`, затем импортирует в `.migrationqa`.
Используются только QA-реквизиты, не реальные Telegram-токены.

Проверены сертификат назначения, отличие UID, каналы, очередь с дорожками,
архив/отметки, настройки и реквизиты. Незавершённое задание остаётся PAUSED с
нулевым прогрессом, расписание выключено, SAF/публикационные URI не перенесены.
Реквизиты сохранены шифротекстом нового Keystore и читаются новым ключом;
исходный шифротекст новым ключом не расшифровывается. Журнал импорта очищен.

Источник: `OK (1 test)`, 6.379 с. Назначение: `OK (1 test)`, 1.975 с.
Полный DataTransferTest в подписанном QA-пакете: `OK (6 tests)`, 17.596 с,
включая неправильный пароль/непустую базу, rollback, нечитаемые данные и
идемпотентное восстановление настроек после прерывания записи.
Локально: 149 JVM-тестов и 27 Python-тестов проходят. Итоговый migrationQa lint:
0 ошибок, 12 предупреждений; сборка завершена успешно.

Первый запуск раннера упал до теста: R8 приложения удалил `androidx.tracing.Trace`.
Для отдельно загружаемого тестового APK добавлены shared API keep rules только
в `migration-qa-app.pro`; compile-time предупреждение `Modifier` ограничено
`migration-qa-test.pro`. Release/legacyBeta правила не изменены. Это локальная
ошибка тестовой сборки, а не VPN или доказанный дефект переноса.

## Не Закрыто Этим Прогоном

Точный будущий публичный APK с исходным package ID и окончательной версией,
его установка после согласованного плана перехода, большой реальный архив,
несколько папок/провайдеров и перезапуск процесса в document picker ещё требуют
приёмки. Fixture QA имеет дополнительные тестовые keep rules и не является
байт-в-байт публичным кандидатом. ARM/API26/35+, 16-КБ страницы, TalkBack,
полные соответствующие исходники runtime, advisories и независимая защищённая
копия ключа остаются обязательными. Исходную beta и её медиа не удалять.

После завершения всех сборок/тестов удалены только восстановимые
`merged_native_libs`/`stripped_native_libs` intermediates, около 1.14 GiB.
`app/build` уменьшен с 2.8 до 1.6 GiB. APK, mapping, отчёты и диагностика
сохранены; shared task-output cache (1.2 GiB), SDK/runtime и ключи не очищались.
