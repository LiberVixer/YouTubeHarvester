обязательных пунктов. Публикация и теги не выполнялись; сертификат основной beta

Смена номера не меняет сертификат тестовых APK и не закрывает обязательные

## Приёмка dev33 (История)

Оптимизированный beta-exporter проверен через системный выбор файла; зашифрованный
экспорт независимо расшифрован и сравнен с установленной базой. Неверный пароль
и непустая база вызывают отказ без перезаписи данных. Исправлена невидимость
результата переноса в Настройках; успешное сообщение и отказ наблюдались в beta.
149 JVM, 21 Python и 36 выбранных device-тестов прошли; lint: 0 ошибок / 24
предупреждения. Все четыре APK проверены и тестовые копии обновлены.
Журналы и SHA-256: `build/qa-dev33/`. Полные границы:
[RELEASE-FIXES-dev33.ru.md](RELEASE-FIXES-dev33.ru.md).

Дополнительно: импорт реального экспорта beta в отдельный пакет с постоянной
подписью и новым UID проверен через интерфейс. Безопасная нормализация записей,
очистка журнала и SAF-перепривязка реального файла подтверждены. Шесть тестов
переноса в подписанном QA-пакете прошли, в том числе повторное шифрование
искусственных Telegram-реквизитов и отказ чтения старого шифротекста новым
Keystore. 27 Python-тестов проходят. Это не финальная приёмка публичного APK;
подробности и ограничения: [MIGRATION-QA-dev33.ru.md](MIGRATION-QA-dev33.ru.md).

## Обязательные Пункты

| Пункт | Что требуется |
| --- | --- |
| R01: постоянная подпись | Новый ключ создан, alias и fingerprint проверены; копия в `/media/sf_Data/Android-signing` проверена по SHA-256, но это общая папка VirtualBox; независимый носитель и защита доступа на хосте ещё не подтверждены |
| Миграция пользователей beta | Реальный экспорт/импорт и SAF-перепривязка проверены в отдельной установке с постоянной подписью; разные UID/Keystore проверены fixture-тестом. Нужны приёмка точного публичного кандидата, большой архив и несколько папок. Основную beta не удалять |
| Историческая beta | Обновление dev32 -> dev33 сохраняет реальные записи и настройки; для более ранних beta нужен исторический APK и отдельная приёмка |
| R02: лицензия | GPL-3.0-only явно утверждена владельцем; `android/LICENSE` добавлен, desktop и сторонние лицензии не менялись |
| R02: исходники runtime | Подготовить соответствующие исходники всех встроенных native/runtime-компонентов, патчи, инструкции сборки и лицензии; имеющийся libwebp не закрывает весь комплект |
| Безопасность runtime | Проверить advisories для фактически встроенных версий и применимость; при необходимости пересобрать runtime и повторить приёмку |
| Матрица устройств | ARM-телефон, поддерживаемый старый API, Android 15+ boot/Resume, устройство с 16-КБ страницами; LDPlayer x86_64/API 34 это не заменяет |
| Доступность | TalkBack и сквозная ручная проверка всех экранов; крупный шрифт/RTL проверены лишь в описанном объёме |
| Публичный кандидат | Утвердить новую release-версию и versionCode выше `120033`, собрать оптимизированные APK уже с постоянной подписью и повторить приёмку кандидата |
| Исходники приложения | Зафиксировать только согласованные Android-изменения; не включать чужие несвязанные desktop-правки |
| Упаковка | Совпадающий Android-тег, четыре проверенных APK, исходники приложения/runtime, BUILD-INFO и SHA256SUMS; dry-run/проверка до публикации |

Порядок: подпись и лицензия; миграция и полный исходный комплект; матрица
устройств; финальный подписанный кандидат; проверенная упаковка; публикация.
Рабочие команды и секреты перечислены в [RELEASING.md](RELEASING.md).

## Подготовка Подписи И Исходников

2026-10-03: утилита создания ключа теперь запрещает перезапись сертификата
и dangling key symlink, создаёт новый каталог с правами 0700, keystore и
сертификат с 0600, выводит SHA-256 публичного сертификата. Четыре новых теста
проходят; реальные секреты в тестах не используются. После первого отказа
автоматической проверки владелец явно выбрал новый ключ и утвердил GPL-3.0-only.
Ключ создан локально с вводом пароля владельцем, alias `yth-android`, RSA 4096.
Приватный файл находится вне Git и имеет 0600, каталог 0700. OpenSSL подтвердил
подпись сертификата и SHA-256:
`25bec4a973717a990f023b7dc07b2588629883c268d71ed820956c0f8bca23ca`.
В проект добавлен только публичный сертификат; сведения в
[signing/README.md](signing/README.md). Публичные APK ещё не подписывались.
По указанному владельцем пути `/media/sf_Data/Android-signing` без перезаписи
сохранены `release.p12` и `release.cert.pem`; SHA-256 обеих копий совпадает с
оригиналами. Путь оказался общей папкой VirtualBox (`vboxsf`), показывающей
права 0777, а не подтверждённым независимым внешним носителем. Защита доступа
на Windows-хосте и независимая offline-копия ещё требуют подтверждения,
поэтому R01 пока не закрыт полностью. Пароль не получен через чат, не сохранялся
агентом и не копировался вместе с ключом.

`android/LICENSE` совпадает с исходным предложенным текстом GPLv3; применение
GPL-3.0-only зафиксировано в `legal/README.md` и NOTICE только для Android-модуля.
Полный исходный комплект компонентов по-прежнему не готов.

Инвентаризация четырёх APK выполнена; перечень и наблюдаемые версии:
[RUNTIME-PROVENANCE.ru.md](legal/RUNTIME-PROVENANCE.ru.md). В NOTICE добавлены
OpenSSL и PyCryptodome. Исходный комплект R02 этим не закрыт. Все 21 Python-тест
скриптов проходят. Код приложения и APK в этой подготовке не менялись.
